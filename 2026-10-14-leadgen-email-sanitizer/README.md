# leadgen-email-sanitizer\n\nA tiny, **CPU‑only** Python CLI that cleans up lead‑generation contact lists for loan‑origination or e‑commerce outreach.\n\n- Validates email syntax with a lightweight regex (no external services).\n- De‑duplicates entries by email.\n- Exports a clean CSV/JSON ready to feed into your marketing funnel or CRM.\n- Optionally saves the invalid rows for manual review.\n\n## Why this matters #Finance #AIMastery #Strategy\n\nSuryoday Bank and Teddy3 need high‑quality lead data to keep acquisition costs low. Bad emails bounce, damage sender reputation, and waste spend. This tool turns a noisy spreadsheet into a SaaS‑ready micro‑service that could be sold for $5‑20 / month per user (or per 10k contacts).\n\n## Features\n- **One‑click** processing of CSV or JSON files.\n- **Configurable** output format (CSV/JSON).\n- **Zero‑cost** – pure Python stdlib, no API keys.\n- **Modular** core functions (`is_valid_email`, `dedupe_contacts`, etc.) can be imported into larger pipelines (n8n, Railway, etc.).\n\n## Installation\n```bash\npip install leadgen-email-sanitizer  # or copy the repo\n```\n\n## Usage\n```bash\npython main.py leads.csv --out-dir cleaned --format json --keep-invalid\n```\n\n- `leads.csv` – your raw list.\n- `--out-dir` – where `clean_contacts.json` and optional `invalid_contacts.json` are saved.\n- `--format` – choose `csv` or `json`.\n- `--keep-invalid` – keep a file with rows that failed validation.\n\n## Example\n```text\nProcessed 1,254 contacts.\n✅ Valid emails: 1,210\n❌ Invalid emails: 44\n✅ Clean file written to cleaned/clean_contacts.csv\n⚠️ Invalid file written to cleaned/invalid_contacts.csv\n```\n\n## Extending the tool\nThe core functions live in `main.py` and can be imported:\n```python\nfrom main import is_valid_email, dedupe_contacts\n```\nAdd MX‑record checks, domain reputation APIs, or integrate with n8n for automated daily runs.\n\n## License\nMIT – free for commercial use.\n\n---\nBuilt for the **Financial Independence** pillar, targeting Suryoday Bank lead‑gen and Teddy3 inventory outreach.\n
