# Decision Impact Simulator

**Category:** #AIMastery #Strategy #Finance

## Overview
`decision-impact-simulator` is a tiny Python CLI that helps founders and analysts gauge the strategic weight of competitor announcements. Feed it a news article URL or a local text file, and it will:

- Extract readable text (no heavy AI models).
- Detect key actions such as price changes, product launches, partnerships, funding rounds, and regulatory events.
- Assign a numeric impact score (0‑100) based on simple heuristic weights.
- Emit a clean Markdown report (and optional JSON) ready for newsletters, internal briefings, or downstream SaaS pipelines.

## Why It Matters
- **Fast, low‑cost intel** – runs on any CPU‑only Windows box.
- **SaaS‑ready** – wrap the core library (`detect_actions`, `score_actions`) into an API or subscription service for $5‑20/month.
- **Modular** – core logic lives in pure functions, easy to plug into n8n workflows, Railway back‑ends, or larger decision‑engine platforms.

## Installation
```bash
pip install decision-impact-simulator
# required extras
pip install requests beautifulsoup4
```

## Usage
```bash
# From a remote article
python -m decision_impact_simulator https://example.com/competitor-news.html

# From a local file, write report to custom path and get JSON output
python -m decision_impact_simulator ./news.txt -o ./my-report.md --json
```

## Sample Report
```markdown
## Competitor Impact Report for `https://example.com/competitor-news.html`

**Impact Score:** 85/100

**Detected Actions:**
- **Product** detected (keyword: `launch`)
- **Funding** detected (keyword: `Series B`)
- **Partnership** detected (keyword: `collaboration`)

*Generated by **Decision Impact Simulator** – a lightweight strategic aid.*
```

## Extending the Tool
The library functions are deliberately simple:
- `detect_actions(text)` – returns a list of `(action_type, keyword)` tuples.
- `score_actions(actions)` – aggregates a score.
- `generate_report(source, actions, score)` – builds markdown.

You can import them in your own services:
```python
from decision_impact_simulator import detect_actions, score_actions
```
