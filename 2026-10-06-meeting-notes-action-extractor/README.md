# Meeting Notes Action Extractor\n\nA tiny, CPU‑only CLI that turns free‑form meeting transcripts into a clean Markdown task list.\n\n## Features\n- Detects bullet‑point style actions, optional owners (`@john`) and due dates (`by 2024-11-01`, `by tomorrow`).\n- Outputs a ready‑to‑paste `# Action Items` markdown section.\n- Zero‑cost – only Python standard library, perfect for Windows laptops without a GPU.\n- SaaS‑ready: wrap the script in a tiny Flask/FastAPI service and charge $5‑20/mo per user.\n\n## Installation\n```bash\n# Clone the repo\ngit clone https://github.com/yourname/meeting-notes-action-extractor.git\ncd meeting-notes-action-extractor\n# No external deps – optional virtualenv\npython -m venv .venv && source .venv/bin/activate\n```\n\n## Usage\n```bash\npython main.py notes.txt        # prints markdown to stdout\npython main.py notes.txt -o actions.md   # writes to file\n```\n\n*`notes.txt`* can be any plain‑text meeting transcript.\n\n## Example\n```
- Discuss Q4 roadmap (by 2024-10-15) @alice\n- Review budget numbers (by tomorrow) @bob\n- Set up demo for client\n```\n\nProduces:\n```markdown\n# Action Items\n\n- [1] Discuss Q4 roadmap @alice (due: 2024-10-15)\n- [2] Review budget numbers @bob (due: 2024-10-08)\n- [3] Set up demo for client\n```\n\n## Extending to SaaS\nWrap the `extract_actions` function in an API endpoint, store results per user in a tiny SQLite DB, and bill via Stripe.
