# loan‑lead‑nurturer\n\nA tiny Python CLI that turns a raw CSV of Suryoday Bank loan leads into a **score‑driven action plan**.\n\n- **Score** each lead with a lightweight heuristic (business type, requested amount, credit score).\n- Flag high‑priority leads for immediate call‑backs.\n- Auto‑schedule follow‑up dates for low‑priority leads.\n- Output a clean JSON report that can be consumed by any SaaS front‑end (React, Firebase, etc.).\n\n## Why this is SaaS‑ready\n- Fixed monthly price ($5‑20) for a hosted endpoint that runs the CLI on demand.\n- Stateless: feed a CSV, get back a JSON payload – perfect for a serverless function on Railway or Vercel.\n- Modular core (`score_lead`, `schedule_followup`, `process_leads`) can be imported into larger lead‑gen pipelines (n8n, Airflow, etc.).\n\n## Features\n- **Zero‑GPU, CPU‑only** – pure Python standard library (optional `tabulate` for pretty printing).\n- Configurable score threshold and follow‑up interval via CLI flags.\n- Handles missing data gracefully, defaults to today for follow‑up calculations.\n\n## Installation\n```bash\n# clone repo\ngit clone https://github.com/yourname/loan-lead-nurturer.git\ncd loan-lead-nurturer\n# optional: install tabulate for nicer console output\npip install tabulate\n```\n\n## Usage\n```bash\npython main.py --input leads.csv --output report.json --threshold 0.6 --followup-days 4\n```\n- `leads.csv` must contain at least the columns: `lead_id`, `business_type`, `requested_amount`, `credit_score`, `last_contact` (YYYY‑MM‑DD).\n- The script prints a summary table and writes `report.json` with entries like:\n```json\n[{\n  "lead_id": "L123",\n  "score": 0.78,\n  "priority": "high",\n  "action": "call_immediately"\n},{\n  "lead_id": "L124",\n  "score": 0.42,\n  "priority": "low",\n  "action": "schedule_followup",\n  "followup_date": "2026-10-21"\n}]\n```\n\n## Extending the tool\n- Replace `score_lead` with a ML model or Groq/Claude call for richer predictions.\n- Hook the JSON output into a webhook that creates tasks in a CRM (n8n, Zapier).\n- Add a `--api-key` flag and expose the logic via FastAPI for a true micro‑service.\n\n##
