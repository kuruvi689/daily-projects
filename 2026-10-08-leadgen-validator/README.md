# LeadGen Validator\n\nA tiny, Python‑only CLI that cleans and validates lead lists for loan‑origination teams.\n\n## 🎯 Aim\n- **Financial Independence** – Turn noisy CSVs into sell‑ready lead bundles, reducing manual vetting time and increasing conversion rates.\n- **#AIMastery #Strategy #Finance**\n\n## ✨ Features\n- Validates email format and (optionally) MX records.\n- Validates phone numbers using a simple E.164‑compatible regex.\n- Adds two columns (`email_valid`, `phone_valid`) to the original CSV.\n- Generates a concise human‑readable summary report.\n- Zero‑config, runs on any Windows CPU‑only machine.\n\n## 📦 Installation\n```bash\npip install -r requirements.txt  # dnspython is optional – install for MX checks\n```\n\n## 🚀 Usage\n```bash\npython main.py leads.csv -o cleaned.csv -s report.txt\n```\n- `leads.csv` must contain at least `email` and `phone` headers.\n- `cleaned.csv` receives the original rows plus validation flags.\n- `report.txt` shows totals and percentages.\n\n## 🛠️ Extensibility\n- The core `validate_email` and `validate_phone` functions are pure Python and can be imported into larger SaaS back‑ends (e.g., n8n workflows, FastAPI services).\n- Swap the regex or plug in a third‑party phone‑validation API without touching the CLI logic.\n\n## 💰 SaaS Potential\nOffer this as a micro‑service (`$5‑$20/mo`) where users upload CSVs via a simple web UI, receive the enriched file and analytics, and pay per month for unlimited runs.\n\n## 📜 License\nMIT – free for personal and commercial use.\n\n## 🙋‍♂️ Author\nBuilt for Sivanesh’s Suryoday Bank lead‑gen pipeline.\n
