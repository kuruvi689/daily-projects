# Cashflow Signal CLI \n\n**Category:** Strategic Sharpness – #AIMastery #Strategy #Finance\n\n## Overview\nCashflow Signal CLI is a lightweight Python command‑line tool that ingests a simple CSV of personal or business transactions, auto‑categorises spending, produces a month‑by‑month financial summary, and flags unusual spikes using a rolling‑window Z‑score algorithm. The output is a clean JSON file that can be fed into dashboards, SaaS billing, or downstream analytics.\n\n## Why it matters\n- **Micro‑service ready** – expose the JSON via a tiny FastAPI wrapper for a $5‑20/mo subscription.\n- **Modular core** – categorisation, aggregation, and anomaly detection are pure functions, reusable in larger finance platforms.\n- **Zero‑cost dependencies** – only Python standard library, perfect for CPU‑only Windows machines.\n- **Actionable insights** – instant alerts on spending spikes help users curb waste and negotiate better contracts.\n\n## Features\n- CSV input with columns `date, amount, description`.\n- Keyword‑based auto‑categorisation (extendable via `category_rules`).\n- Monthly totals and per‑category breakdowns.\n- Spike detection using a rolling 3‑month window and Z‑score threshold (default 2.0).\n- JSON output (`summary.json` by default) and console summary.\n\n## Installation\n```bash\n# Clone the repo\ngit clone https://github.com/yourname/cashflow-signal-cli.git\ncd cashflow-signal-cli\n# No external packages required – just Python 3.9+\npython -m pip install -r requirements.txt  # (empty)\n```\n\n## Usage\n```bash\npython main.py transactions.csv -o my_report.json\n```\n- `transactions.csv` – your raw export from banks or accounting tools.\n- `-o` – optional path for the JSON report.\n\n## Sample CSV\n```csv\ndate,amount,description\n2026-01-05,1200,Salary November\n2026-01-10,-45,Uber ride\n2026-01-12,-150,Amazon purchase\n2026-02-03,-2000,Rent February\n...\n```\n\n## Extending the tool\n- **Custom categories** – edit `category_rules` in `main.py`.\n- **Different windows/thresholds** – modify `detect_spikes` arguments.\n- **API wrapper** – expose `summarize` and `detect_spikes` via FastAPI for SaaS delivery.\n\n## License\nMIT – free for personal and commercial use.\n\n---\nBuilt for Sivanesh’s strategic finance automation toolbox.\n
